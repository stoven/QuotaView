# QuotaView Brand Refresh Proposal

This folder contains a visual proposal only. It does not replace the production
AppIcon or menu-bar asset.

## Direction: Q Lens

- The outer ring represents a quota boundary.
- The inner chevron forms a `V` for View.
- The lower-right tail turns the ring into a `Q` for QuotaView.
- The app icon uses graphite, ceramic white, and one restrained mint quota cue.
- The menu-bar icon is a monochrome macOS template drawing on a `20 × 16 pt`
  canvas. Its visible artwork occupies the left `15 × 16 pt`, leaving a `5 pt`
  transparent area on the right for the system text gap.

## Deliverables

- `QuotaViewAppIcon-v2.png`: 1024 × 1024 app-icon proposal with alpha corners.
- `QuotaViewMark-v2.svg`: exact flat geometry and palette reference.
- `QuotaViewMenuIcon-v2.svg`: production-scale monochrome template proposal.
- `QuotaViewMenuIcon-v2-preview.png`: enlarged light/dark menu-bar preview.

Production adoption requires a dedicated accepted SDD brand-change spec and
product-owner approval.
