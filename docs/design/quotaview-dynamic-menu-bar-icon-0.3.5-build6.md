# QuotaView 动态菜单栏图标规格

> 文档编号：`QV-PRODUCT-DYNAMIC-MENU-BAR-004`
>
> 目标版本：QuotaView `0.3.5 (Build 6)`
>
> 规格状态：`Accepted`
>
> 交付状态：`Verifying`
>
> 接受与实施授权：产品所有者于 2026-08-13 明确要求将菜单栏图标更新为
> 随剩余额度从 100% 满到 0% 空动态变化的生产行为。

## 1. 目标

菜单栏图标使用已经确认的无红点“潮汐窗”方向，把主周期剩余额度直接编码
为图形内部的填充高度。用户无需先读取数字，也能快速感知额度由满到空的
变化；图标仍保持 macOS 菜单栏的紧凑、单色和模板图像语义。

## 2. 范围

- 使用 `CurrentCodexPresentation.remainingPercent` 作为唯一数据源；
- 100% 显示为完全填满，0% 显示为空，区间值按比例单调变化；
- 有效百分比更新时执行短时平滑过渡；
- 无快照或最新请求失败时显示独立的不可用轮廓，不得伪装成 0%；
- 设置页菜单栏预览使用同一绘制模型与当前状态；
- 保持既有菜单栏文字、倒计时、可见性设置、逻辑画布和辅助功能语义。

## 3. 非目标

- 不替换 macOS App Icon、主面板 Header 图标或 Widget 图标；
- 不改变额度计算、刷新周期、请求协议或状态风险分级；
- 不新增彩色状态点、红点、渐变、光晕或菜单栏背景；
- 不授权签名、公证、tag、GitHub Release 或 appcast 发布。

## 4. Requirement

### `MENU-ICON-01` — 原生潮汐窗几何

图标必须由 AppKit 原生矢量路径绘制为模板图像。可见本体保持
`15 × 16 pt`，`NSImage` 逻辑画布保持 `20 × 16 pt`，图形左对齐并在右侧
保留 `5 pt` 透明区，继续得到约 `8 pt` 的最终图文间距。外轮廓与顶部窗口
缺口在所有状态下保持稳定，不使用红点。

### `MENU-ICON-02` — 百分比到填充的映射

有效剩余百分比先夹取到 `0...100`，再线性映射为 `0...1` 填充比例。
`100%` 的内窗必须完全填满，`50%` 接近半满，`0%` 必须完全为空；中间值
随剩余百分比单调变化。填充边界允许使用克制的不对称曲线表达潮汐感，但
不得改变数值映射或遮挡外轮廓。

### `MENU-ICON-03` — 状态更新与动效

首次获得有效快照时直接显示真实比例，不能从虚构的 0% 动画到当前值。
后续有效值变化以 `0.18 s` ease-out 过渡到目标，包括额度减少与重置后增加。
新数据到达时从当前视觉值继续，不得跳回上一个起点。启用 macOS“减少动态
效果”后取消插值并立即使用目标值；隐藏图标或进入不可用状态时停止计时器。

### `MENU-ICON-04` — 无数据与可访问性

无快照或最新请求失败时使用“空轮廓 + 内部短横线”的不可用图形，使其与
真实 `0%` 的空轮廓可区分。菜单栏 Tooltip 和 VoiceOver 继续使用现有本地化
状态文本：有效状态读出真实百分比，失败读出错误，连接中读出正在连接；
不能由图形生成虚构数值。

### `MENU-ICON-05` — 设置与入口不变量

“显示图标”“显示剩余额度”“显示重置倒计时”的既有约束保持不变。设置页
菜单栏预览使用相同动态图标状态。至少保留图标、百分比或倒计时中的一项，
应用入口不得消失。

### `MENU-ICON-06` — 验证门禁

自动化至少覆盖百分比夹取、0/50/100 映射、不可用与真实 0% 的区分、插值
端点与模板画布尺寸。`swift test` 和 Universal Release 无签名构建必须通过；
图标在真实菜单栏中的轮廓、填充识别和过渡观感由产品所有者运行后验收，
未确认前不得记录为视觉通过或 `Released`。

## 5. 失败与降级语义

- 百分比越界：只在渲染模型中夹取，不修改业务快照；
- 快照缺失或请求错误：立即显示不可用图形，不保留过期填充；
- 动画被中断：以当前视觉值为新起点继续到最新目标；
- 减少动态效果：不动画，直接呈现目标；
- 图标被隐藏：停止图标动画，文字入口继续按偏好显示。

交付状态保持 `Verifying`。
